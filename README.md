# Mami Saveurs

Landing page responsive d'un restaurant de cuisine béninoise traditionnelle à Porto-Novo, avec livraison à domicile.

🔗 **Démo en ligne :** https://sweet-cascaron-5d4e58.netlify.app

![Aperçu de la page](images/hero.jpg)

## Fonctionnalités

- Mise en page responsive, du mobile (320 px) au grand écran
- Grille de plats adaptative avec `auto-fit` et `minmax`
- Hero avec zones nommées (`grid-template-areas`)
- Animations et transitions, avec respect de `prefers-reduced-motion`
- Liens du pied de page générés en JavaScript depuis un tableau de données

## Technologies

- HTML sémantique
- CSS : Flexbox, Grid, variables, media queries mobile-first
- JavaScript : manipulation du DOM

## Ce que j'ai appris

- Intégrer une page à partir d'une maquette et d'une fiche de style
- Choisir entre Flexbox et Grid selon la mise en page
- Rendre une page accessible (sémantique, focus clavier, mouvement réduit)
